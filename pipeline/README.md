# UPTH No-Show Data Pipeline

This folder contains the data pipeline developed for Module 3 of my BAN6800 capstone project.

The pipeline is designed to prepare the Medical Appointment No Shows dataset for predictive modeling through data ingestion, cleaning, transformation, validation, and responsible data preparation.

## Planned Pipeline Stages

1. Data ingestion
2. Data cleaning
3. Data transformation
4. Data validation
5. Privacy and bias checks
6. Model-ready dataset preparation

Prefect will be used to orchestrate the pipeline workflow.
